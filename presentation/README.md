# Presentation

Beamer slides (LMU colours, English).

## View / compile

```bash
cd presentation
/Library/TeX/texbin/pdflatex main.tex
/Library/TeX/texbin/pdflatex main.tex
open main.pdf
```

Or upload `main.tex` (+ optional `resources.bib`) to Overleaf and click **Recompile**.

Plots from the notebooks can go into `figures/`; uncomment the `\includegraphics` lines in `main.tex`.
