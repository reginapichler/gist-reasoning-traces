## Project

We investigate reasoning traces in the context of extracting greenhouse gas emissions data from corporate sustainability reports, building on the [climatextract pipeline](https://github.com/gist-sustainability/climatextract).

Our focus is on analysing the traces alongside extracted values and reference data to explore their usefulness for understanding extraction decisions and errors.

## Repository Contents

This repository will contain analysis code, trace annotations, and results. The exact experimental setup will be developed during the seminar.
